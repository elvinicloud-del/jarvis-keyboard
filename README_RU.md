# JARVIS Keyboard — исходный проект

Это минимальный Android Input Method Service (клавиатура), который собирается через GitHub Actions.

## Сборка APK
1. Создайте на GitHub новый пустой репозиторий.
2. Загрузите в него **содержимое этой папки**, сохранив структуру каталогов.
3. Откройте вкладку Actions и запустите `Build JARVIS Keyboard APK` (или дождитесь автоматической сборки после загрузки файлов).
4. В завершившемся запуске скачайте артефакт `JARVIS-Keyboard-debug`.
5. Внутри архива будет `app-debug.apk`.

## Важно
Это ранний прототип. В нём есть RU/EN/AZ раскладки, включая часть азербайджанских букв, базовый ввод, удаление, пробел, Enter и кнопку скрытия. Пока нет словарей, автокоррекции, предсказаний, полноценной панели настроек и голосового ввода. Перед публикацией потребуются тестирование и доработка.
